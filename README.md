# ERP-система для коворкинга WorkHub City Center

Современная веб-система управления коворкинг-пространством на базе React + TypeScript + Vite.

## 🚀 Возможности

- ✅ **Дашборд** - статистика, графики загрузки, последние бронирования
- ✅ **Управление бронированиями** - поиск, фильтрация, CRUD операции
- ✅ **База резидентов** - карточки клиентов с контактами
- ✅ **Аналитика** - графики выручки, загрузки по зонам, распределение тарифов
- ✅ **Экспорт данных** - выгрузка в CSV
- ✅ **Полная русская локализация**
- ✅ **Адаптивный дизайн** - работает на всех устройствах
- ✅ **Темная тема** - современный Material-UI интерфейс

## 🛠 Технологии

- **Frontend:** React 18 + TypeScript
- **Build Tool:** Vite
- **UI Framework:** Material-UI (MUI)
- **Routing:** React Router v6
- **Charts:** Recharts
- **Internationalization:** i18next
- **HTTP Client:** Axios

## 📦 Установка
```bash
# Клонировать репозиторий
git clone https://github.com/deleoningram/coworking-erp.git
cd coworking-erp/frontend

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Приложение откроется на http://localhost:5173

## 📊 Модули системы

### 1. Дашборд
- Ключевые метрики (бронирования, загрузка, выручка)
- График загрузки по часам
- Таблица последних бронирований
- Список резидентов и тарифов

### 2. Бронирования
- Поиск по ID, ресурсу, клиенту
- Фильтрация по статусу и оплате
- Цветовая индикация статусов
- Удаление записей
- Экспорт в CSV

### 3. Резиденты
- Карточки клиентов
- Поиск по имени и email
- Контактная информация
- Статус активности
- История сотрудничества

### 4. Аналитика
- График выручки vs план
- Диаграмма распределения тарифов
- Загрузка по зонам
- KPI метрики с динамикой
